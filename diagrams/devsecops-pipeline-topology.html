ETAPA 01-A
🖥️
IDE + Plugins de Segurança
Feedback em tempo real enquanto o código é digitado. Vulnerabilidade encontrada aqui tem custo zero de correção — o dev corrige antes mesmo de salvar o arquivo.
SonarLint
Snyk IDE
Semgrep Extension
📊 Alerta inline na IDE
Princípio do Shift-Left: corrigir aqui custa próximo de zero. Em produção, o mesmo problema pode custar 100x mais. É o primeiro elo do SSDLC — segurança integrada desde a fase de código.
ETAPA 01-B
🔐
Pre-commit Hook
Executa automaticamente antes de cada git commit. Se encontrar problema, bloqueia — o código não sai da máquina.
Gitleaks
detect-secrets
pre-commit framework
🚫 Bloqueia o commit
Foco principal: credenciais expostas — senhas, tokens de API, chaves privadas e connection strings hardcoded no código. É o último filtro antes do código chegar ao repositório.

BUILD
📦
Artefato Assinado Digitalmente
Cosign  ·  SLSA  ·  in-toto
SBOM arquivado e vinculado a esta versão · Imutável no Artifact Registry
A assinatura garante que o que foi testado no CI é exatamente o que vai para produção. Se alguém alterar a imagem depois do build, a assinatura quebra e o deploy é rejeitado.
↓ deploy no ambiente de staging → validação dinâmica antes de produção
CD — CONTINUOUS DELIVERY — validação final antes de produção
ETAPA 07
💥
DAST
Testa a aplicação em execução simulando ataques reais. Valida autenticação, autorização, headers de segurança e comportamento sob ataque. Roda contra staging — nunca produção.
OWASP ZAP
Acunetix
Burp Suite Enterprise
Nuclei
🚫 Bloqueia deploy prod
Diferente do SAST: aqui a aplicação está rodando. O teste simula um atacante real tentando invadir — valida o que o código faz de fato, não só o que foi escrito.
CONTROLE

🚫 Pod sem assinatura
Guardrail do Kubernetes. Nenhum container sobe em produção sem ter sido assinado pelo pipeline — mesmo que alguém tente fazer deploy manual.
